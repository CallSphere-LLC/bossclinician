## Change and policy

An enabled completion template (direct course or linked product) or the existing course flag requires media viewing. Known durations require 95% contiguous server-credited playback; unknown durations retain the existing time-bounded 90% fallback. Actual media URLs determine whether a lesson has media, even when mislabeled text. Old ticks alone do not satisfy the new gate. Stored progress rows and existing certificates are not deleted or revoked.

Migration 161 only adds course_watch_exemptions. No learner is exempted automatically. A products.manage administrator can recognize or revoke verified prior Kajabi viewing for exactly one course/member, with a required reason and atomic before/after audit. This waives viewing only; it creates no grant, progress, assessment, certificate or email. Noncertificate course toggle behavior remains.

Duplicate outline slugs are qualified after the first occurrence as slug--lesson-ID. The original first URL remains. IDs and stored lesson slugs do not change. All links must use the outline's returned slug (including search). Reserved-slug collisions are avoided and qualified routes fit the 200-character limit.

Certificate status returns an optional nextRequiredLesson {id,slug,title}, selected from entitled/unlocked lessons. The course home lists videos/evaluations still needed and links to that lesson. No certificate is issued on a status read.
