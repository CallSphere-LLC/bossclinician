# TidyCal booking sync

Boss Clinician keeps the public booking form and local coaching calendar. When sync is enabled, public free-call slots are intersected with TidyCal availability, a TidyCal booking is created before the local booking is confirmed, and guest cancellations are sent to TidyCal before being marked cancelled locally. Existing bookings are not backfilled.

The integration requires a paid TidyCal account and a Personal Access Token from Integrations > Advanced > Manage API keys > Personal tokens. Put it only in `backend/.env` as `TIDYCAL_API_TOKEN=...`; never in the tracker or frontend env. After deployment, compare the imported `legacy_slug` and duration of each free call type with the account's TidyCal booking types. Both must match exactly, be active, and be free. After comparing types, set `TIDYCAL_SYNC_ENABLED=true`, redeploy, and test a disposable booking and cancellation before relying on the sync. Until that flag is true, local booking behavior is unchanged.

The integration fails closed when TidyCal is unavailable or a type is unmatched, so it does not silently accept an unsynced booking. An external booking ID is stored with each synced local session. If TidyCal confirms a booking but the local insert fails before commit, the integration requests a compensating cancellation and logs a failure for investigation. Do not claim two-way sync: edits or cancellations made directly in TidyCal, member-coaching bookings, and historical bookings are not yet reflected back into Boss Clinician.
